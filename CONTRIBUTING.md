# Contributing

Thanks for contributing to this project.

## Setup

```bash
git clone https://github.com/InfinitePraveen/topic-modeling-news-articles.git
cd topic-modeling-news-articles
python -m venv .venv
pip install -r requirements.txt
```

## Guidelines

1. Keep notebooks focused and readable.
2. Use descriptive variable names.
3. Explain important NLP decisions in markdown cells.
4. Do not commit large raw datasets or generated model binaries.
5. Keep the Flask app simple and understandable.
6. Test notebook and web-app changes before submitting a PR.
7. Update the README when the workflow changes.

## Pull Requests

Include a short description, motivation, testing steps, and screenshots when UI changes are involved. Prefer small, focused pull requests.
